# MFA Front Desk — MVZ Journey (As-Is) (FigJam Ready)

## How to use
- Copy each section into FigJam
- Convert each bullet into sticky notes
- Use color coding:
  - Blue = Actions
  - Purple = Touchpoints
  - Yellow = Thoughts
  - Red = Pain Points
  - Green = Opportunities

---

## PHASE 1 — Day Start & Preparation

### Actions
- Log into PVS + boot devices
- Review schedule + patient list
- Process refill requests
- Check offline to-do backlog
- Prepare rooms + doctor allocation

### Touchpoints
- PVS calendar / to-do
- eGK reader, printer
- Phone, fax
- Paper lists

### Thoughts
- Do I have everything ready before 08:00?
- Too many refill requests already

### Pain Points
- Scattered refill channels
- No cross-location visibility
- Flat to-do list (no priority)
- Hardware dependency risk

### Opportunities
- Unified refill inbox
- Cross-location schedule layer
- Priority-based task queue
- System health check dashboard

---

## PHASE 2 — Patient Registration & Intake

### Actions
- Greet + read eGK
- Handle failure → Ersatzverfahren
- Resolve insurance
- Verify documents
- Create/update patient
- Create Schein
- Check HZV/FAV

### Touchpoints
- eGK + TI connector
- Patient record UI
- Schein dialog
- Enrollment module

### Thoughts
- Card failed again
- Which Schein type is this
- Insurance changed

### Pain Points
- eGK blocking flow
- TI errors unclear
- Cost carrier complexity
- Manual Schein selection
- Enrollment hidden
- Queue pressure

### Opportunities
- Seamless fallback flow
- Guided insurance resolution
- Auto Schein inference
- Inline enrollment visibility

## PHASE 3 — Pre-Consultation Support

### Actions
- Handle patient-specific tasks
- Take vitals
- Scan documents
- Record anamnesis
- Assign waiting room
- Signal doctor

### Touchpoints
- Scanner
- Anamnesis form
- Waiting room board

### Thoughts
- Scan now or keep queue moving
- Doctor prefers different format

### Pain Points
- Manual scanning workflow
- No OCR
- Inconsistent anamnesis
- No patient state visibility
- Weak handoff signal

### Opportunities
- Smart document ingestion
- Doctor-specific templates
- Live patient flow board
- Confirmed handoff system
