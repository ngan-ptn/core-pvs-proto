# MFA Front Desk FigJam Journey Map Design

Date: 2026-03-17
Source: `docs/_ngan/JMAP260317-mfa-front-desk.md`
Audience: Product and design team
Consumption mode: Async review
Scope: MFA journey adapted into a FigJam User Journey Map template structure

## Goal

Create a FigJam board that converts the approved MFA front desk journey map into an async-readable workshop artifact using the same template-style structure as the doctor board.

## Main Frame

- Title: `MFA Front Desk - MVZ Journey (As-Is)`
- Layout: horizontal timeline from left to right
- Context note: MFA at the front desk of an MVZ, legacy PVS, 40-60 patients processed per day, continuous multitasking

## Swimlanes

Top to bottom:

1. Phases
2. Actions
3. Touchpoints
4. Thoughts and Emotions
5. Pain Points
6. Opportunities

## Phase Columns

Use six phase columns:

1. Day Start and Preparation
2. Patient Registration and Intake
3. Pre-Consultation Support
4. During-Consultation Support
5. Prescriptions, Forms and Documents
6. Post-Visit and Day Close

## Right-Side Layers

Add a right-side area containing:

- Opportunity clusters:
  - Operational Intelligence
  - MVZ Orchestration
  - Workflow Automation
  - Safety and Billing Accuracy
- Key insight overlay as a large sticky
- Pain severity legend

## Content Rules

- Ground the board in the MFA journey markdown
- Keep wording concise enough for board readability while preserving the original meaning
- Adapt the content into the same template structure used for the doctor board
- Infer opportunities from repeated pain points to fit the requested template pattern

## Delivery

Create the board as a separate FigJam file because the available diagram tool cannot append to the existing FigJam board.
