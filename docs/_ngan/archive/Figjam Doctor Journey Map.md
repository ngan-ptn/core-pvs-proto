## PHASE 1 — Day Start & Preparation

### Actions
- Log into PVS
- Review appointment calendar
- Check unfinished items
- Mentally plan the day
- Print schedule (backup)

### Touchpoints
- PVS calendar
- To-do queue
- Paper schedule

### Thoughts
- 40+ patients today
- Running late already

### Pain Points
- No clinical context in calendar
- No cross-day continuity
- Multi-location disorientation
- Paper shadow system

### Opportunities
- Context-rich calendar
- Unified cross-day queue
- Persistent workspace (MVZ)
- Fast overview dashboard

## Key Insight

Doctor is forced to:
- Context-switch 40–60 times/day
- Balance clinical thinking vs system interaction

Current PVS:
- Task-driven
- Sequential

Reality:
- Cognitive + parallel + time-pressured

→ Design must support:
- **Cognitive offloading**
- **Context continuity**
- **Minimal interruption workflow**
